# NumPy Array Operations

## Project Description

This project demonstrates basic mathematical operations on NumPy arrays using Python. Two NumPy arrays are created, and addition, subtraction, multiplication, and division are performed using vectorized operations.

## Objective

To understand and implement vectorized numerical operations using NumPy.

## Tools Used

- Python
- NumPy
- Jupyter Notebook

## Operations Performed

- Addition
- Subtraction
- Multiplication
- Division

## Key Concepts

- NumPy arrays
- Array shapes
- Vectorization
- Element-wise operations

## Conclusion

This project demonstrates how NumPy performs mathematical operations efficiently on arrays using vectorization, without requiring explicit loops.
